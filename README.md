# Minecraft Advanced (MC 26.2, Fabric)

Клиентский RPG-мод для **Minecraft 26.2** на **Fabric**: 12 уникальных миров,
Главная Комната (хаб) с порталами и торговцами, 12 боссов, 37 новых мобов,
уникальные торги жителей, 169 новых предметов, 4 тира инструмента/брони,
артефакты боссов и собственные биомы с рудами.

## Быстрый старт

```bash
./gradlew build          # сборка
./gradlew runClient      # запуск клиента с модом
./gradlew runServer      # запуск выделенного сервера (валидация)
```

Готовый jar: `build/libs/mcadvanced-1.0.0.jar` — положить в папку `mods`
(нужен Fabric Loader ≥ 0.19.5, Fabric API, Java 25).

## Как играть

1. При первом входе в мир вы получаете **Выбор мира** и **Компас хаба**.
2. ПКМ по «Выбору мира» (или клавиша **K**) — меню телепортации: 12 миров + Главная Комната.
3. В хабе стоят 3 торговца (охотник, алхимик, кузнец) и 12 порталов по стенам.
4. Порталы в хабе ведут в миры; вернуться можно компасом хаба или «Выбором мира».
5. В каждом мире — своя руда (самоцвет), свои мобы и свой босс.
6. Босс призывается **предметом призыва** (крафт: 4 самоцвета + палки + кость)
   или через **Алтарь боссов**, установленный рядом с порталом мира.
7. Души боссов → корона миров; гемы → инструменты/броня 4 тиров
   (адурит/глацит ≈ алмаз, инфернит/нуллит ≈ незерит).
8. Убийство босса даёт **Душу мира** (+2 ❤️ навсегда) и шанс на артефакт.

## Способности игрока

| Клавиша | Способность | Эффект | Кулдаун |
|---------|-------------|--------|---------|
| **R** | Рывок | мощный толчок в направлении взгляда (облако + gust) | 3 с |
| **V** | Боевой перекат | перекат с ~0.6 с полной неуязвимости | 5 с |
| **K** | Выбор мира | меню телепортации по мирам | — |

## Анимации мобов

Мобы анимированы и не стоят «столбом»:
- **Гуманоиды** (бандиты, мумии, големы, боссы, торговцы…): ходьба с размахом рук,
  боевая стойка при агрессии (руки наготове, корпус подан вперёд),
  выпад с замахом при атаке, дыхание/покачивание в покое.
- **Звери** (быки, олени, зебры, львы): диагональный галоп четырёх ног,
  покачивание головы на бегу, «принюхивание» в покое, выпад головой при атаке,
  качание корпуса на скорости.
- Пауки/слаймы/духи используют анимированные ванильные модели.

## Структура проекта

```
src/main/java/.../        — общий код: реестры, мобы, боссы, блоки, предметы, сеть, генератор хаба
src/client/java/.../      — клиент: рендеры мобов, модель зверей, экран выбора мира, кейбинд K
src/main/resources/       — ассеты (текстуры, модели, lang en/ru) и данные (измерения, биомы, руды, лут, рецепты, торги)
tools/                    — Python-генераторы контента (manifest.py — источник истины)
```

## Сборка из архива

Требуется JDK 25 (`sourceCompatibility = 25`). Gradle wrapper 9.7.1 идёт в комплекте.

```bash
unzip mcadvanced-1.0.0-src.zip && cd arenacoding
./gradlew build --no-daemon
```
